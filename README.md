## Featured work

### [API Authentication & RBAC](https://github.com/liz-scudeller/APIAuthRBAC)

Node.js and Express API demonstrating JWT authentication, bcrypt password hashing, least-privilege registration, role-based authorization, separated middleware, and automated security-boundary tests. This is a learning-sized reference implementation, not a production identity platform.

### [Clearance Scout](https://github.com/liz-scudeller/clearance-scout)

React and Node.js business application with Supabase architecture for collecting, validating, deduplicating, enriching, and reviewing clearance-sale data. The README documents human approval boundaries, uncertainty handling, limitations, and synthetic/public-safe integrations.

### [SEO Intelligence Platform](https://github.com/liz-scudeller/seo-intelligence-platform)

Public-safe demonstration of deterministic audits, tenant-aware data modeling, evidence-backed findings, approval workflows, audit logging, and synthetic provider adapters. The runnable demo uses in-memory persistence; production integrations are not claimed.
